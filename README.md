# Buttercup Advertising Studio Website

Official website and portfolio for **Buttercup Advertising Studio** — Creative Branding, Designing, Strategy, and Digital Marketing Agency.

## 🚀 Overview

- **Core Pages:**
  - `home.php` - Homepage with USP counter, services overview, and client testimonials.
  - `projects.php` - Interactive project showcase featuring authentic brand identity case studies.
  - `services.php` - Comprehensive creative and branding services.
  - `aboutus.php` - Studio profile, leadership, and vision.
  - `contactus.php` - Interactive contact and enquiry forms.
- **Client Branding Portfolios:**
  - Vijay Trivedi Group (`vijay-trivedi-branding.php`)
  - Ecoforest (`ecoforest-branding.php`)
  - Farmbyte (`farmbyte-branding.php`)
  - Prajay Steel (`prajay-steel-branding.php`)
  - Gabbar (`gabbar-branding.php`)
  - Jimmy Lifestyle (`jimmy-branding.php`)
  - Packaging Design Portfolio (`packagingdesignportfolio.php`)
  - Brochure Design Portfolio (`brochuredesignportfolio.php`)
  - Logo Design Portfolio (`logodesignportfolio.php`)
  - Brand Guidelines & Systems (`branding-portfolio.php`)
  - Website Design Portfolio (`websitedesignportfolio.php`)
  - Advertising Campaigns (`advertising-design-portfolio.php`)

## 🛠️ Tech Stack

- **Backend:** PHP 8+
- **Frontend:** HTML5, CSS3, JavaScript, jQuery
- **CSS Frameworks:** Bootstrap 4, Custom Design System
- **Icons & Typography:** IcoFont, Google Fonts (Poppins, Inter)

## 💻 Running Locally

To run this website locally on your machine using PHP's built-in web server:

```bash
php -S 127.0.0.1:8888 router.php
```

Then open `http://localhost:8888/` in your browser.
